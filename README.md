# 🎉 Happy Birthday MANOW Web App 🎂

เว็บเซอร์ไพรส์วันเกิดแบบ Interactive สุดพิเศษสำหรับ "มะนาว" ออกแบบมาเพื่อเล่นบน Mobile และ iPad โดยเฉพาะ ✨

## ✨ ฟีเจอร์เด่น (Interactive Stages)
1. **Stage 0: ประตูล็อคอินสุดน่ารัก (Birthday Gatekeeper)**
   - ระบบตรวจสอบชื่อและวันเกิด (รองรับรูปแบบ วัน/เดือน/ปี ทั้ง พ.ศ. และ ค.ศ.)
2. **Stage 1: ห้องมืดกับสายไฟฟิสิกส์ (Dark Room & Light Cord)**
   - สายดึงเปิดไฟแบบฟิสิกส์สมจริง (Verlet Integration) ดึงได้สะใจพร้อมแรงสั่น (Haptics) และเอฟเฟกต์เสียง mechanical switch & sub-bass rumble
3. **Stage 2: เค้กวันเกิดและเป่าเทียน (Birthday Cake & Make a Wish)**
   - เปลวไฟเทียนสมจริง สามารถเป่าผ่านไมโครโฟนมือถือได้จริง หรือแตะเพื่อดับ
   - พลุกระดาษเฉลิมฉลอง (Confetti) พร้อมช่องอธิษฐานส่งตรงเข้า Firebase Realtime Database
4. **Stage 3: จดหมาย, โพลารอยด์ & บัตรขูดลุ้นรางวัล (Celebration & Letter)**
   - ซองจดหมายประทับตราครั่ง (Wax Seal) พร้อมการ์ดอวยพร
   - รูปภาพโพลารอยด์ความทรงจำ ปัดเลื่อนดูได้ (Swipeable Carousel) และแตะเพื่อซูมรูปใหญ่ (Lightbox)
   - **การ์ดขูดลุ้นของขวัญสีทอง (Golden Scratch Card Voucher)** ใช้นิ้วขูดเปิดสิทธิ์แลกของขวัญ และส่งคำขอเข้า Database อัตโนมัติ
